# Veris interface system

Direction: immersive institutional security, with a quiet navy foundation, icy typography, blue actions and cyan orbital highlights. UI UX Pro Max recommendations were adapted to avoid overt cyberpunk styling in an evidence review workflow.

Typography: Manrope display headings, DM Sans body and controls, monospace provenance identifiers. Surfaces use opaque dark panels to preserve readability over procedural 3D. Normal text was raised to at least 4.5:1 against the dark reference surface; primary button contrast is 5.18:1.

Motion: GSAP scroll scrub 1.3s; Framer Motion section reveals; lazy-loaded Three.js scene, bounded DPR, reduced-motion/static fallback and paused hidden-tab rendering. Pointer motion uses document events. Hover/pressed feedback and route transitions are subordinate to the content.

Access: true empty states, durable-job progress, provider-specific error states, authenticated downloads, role-scoped actions, one-use invitations. No simulated source claims or random confidence scores.

Responsive: 375, 768, 1440 and short landscape QA. Keyboard skip link, visible focus, trapped modal focus, inert background/hidden drawer, labelled controls, 44px icon hit areas, password paste/autocomplete and safe-area spacing.
